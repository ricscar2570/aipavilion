# Roadmap verso AI Pavilion 1.0

| Milestone | Obiettivo | Contenuto |
| --- | --- | --- |
| 4.5F | Esperienza, accessibilità e privacy | Sessioni scadute, assenza rete, messaggi d’errore, WCAG manuale, consenso, retention e revisione legale. |
| 4.5G | Prove operative indipendenti | Carico, throttling, concorrenza, restore, WAF, SES, webhook ritardati e penetration test. |
| 0.9.0 | Pilot interno | Deploy AWS ripetibile, dati sintetici, prove complete, runbook e supporto. |
| 0.9.5 | Pilot cliente controllato | Un organizzatore, espositori limitati, monitoraggio diretto e raccolta metriche. |
| 1.0.0 | Prima release commerciale | Core eventi/stand/lead/billing SaaS; nessun marketplace multi-vendor. |
| 1.1+ | Espansioni validate | Booking incontri, streaming, multilingua e analytics avanzate. |
| 2.0+ | Visione immersiva/AI | 360°, AR, semantic search, raccomandazioni e assistenza contenuti, solo se giustificati dai dati. |

## Criteri di uscita per 1.0

- CI riproducibile;
- staging ripetibile;
- zero P0/P1 aperti;
- autenticazione e lifecycle provati;
- lead e billing SaaS provati;
- accessibilità manuale approvata;
- penetration test chiuso;
- restore con RPO/RTO;
- runbook di supporto;
- almeno un pilot completato e un segnale di rinnovo.
